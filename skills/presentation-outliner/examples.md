# Test prompts (used by the automatic self-test)

## 1. Quarterly update for a manager, 10 minutes, notes with 3 metrics
Expected: inform structure with the headline first, about 10-12 slides,
times summing to 10 minutes, the 3 metrics exactly as given, action titles.

## 2. Pitch to get budget for a new tool, no numbers given
Expected: persuade structure, `[add: ...]` for cost and savings,
a clear ask on the last slide, likely questions section.

## 3. Thai class presentation, 5 minutes, "Canva ready"
Expected: Thai, 5-6 slides, on-slide text blocks only.
