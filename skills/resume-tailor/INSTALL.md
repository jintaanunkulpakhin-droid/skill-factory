# How to install this skill

The folder in this zip is a Claude Skill. Its name is the folder name.

**Claude.ai or the Claude desktop app:** open Settings, then Capabilities,
and turn on "Code execution and file creation". Then open Customize, then
Skills, and upload this zip file as it is. Turn the skill on, then just ask
Claude for what the skill does. Skills work on every Claude plan,
including Free.

**Claude Code:** unzip the folder into `~/.claude/skills/` (for all your
projects) or `.claude/skills/` inside one project. Restart Claude Code.

**Try it:** `examples.md` has three test prompts you can paste in.
