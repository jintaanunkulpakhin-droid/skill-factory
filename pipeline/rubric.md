# Quality rubric (score each 0-2, pass at 8/10)
1. Trigger: the description says clearly when to use it, in a buyer's words.
2. Value: output is noticeably better than asking Claude with no skill.
3. Structure: steps, output format and an example are explicit.
4. Robustness: handles messy or missing input without breaking.
5. Safety and honesty: no invented facts, no claims about brands or results.
